# 学霸到家 · 单页面原型说明文档

> 版本：v1.0  
> 约束：空闲授课时间统一日历可视化 | 筛选固定5项（学科/年级/距离/单价区间/院校） | 实名认证状态全局标识（未审核/审核中/已通过/驳回） | 无支付闭环（仅订单记录，线下自行结算）

---

## 全局规范

### 实名认证状态标识规范

| 状态 | 色值 | 图标 | 展示位置 |
|------|------|------|----------|
| 未审核 | #999999 灰色 | ⚠ 圆形灰底 | 个人中心顶部、档案页状态栏 |
| 审核中 | #F5A623 橙色 | ⏳ 圆形橙底 | 个人中心顶部、认证审核中页 |
| 已通过 | #52C41A 绿色 | ✓ 圆形绿底 | 个人中心顶部、老师详情页姓名旁 |
| 驳回 | #F5222D 红色 | ✗ 圆形红底 | 个人中心顶部、认证页驳回提示 |

### 日历组件统一规范

| 属性 | 定义 |
|------|------|
| 组件名 | WeeklyScheduleCalendar |
| 列头 | 周一 / 周二 / 周三 / 周四 / 周五 / 周六 / 周日 |
| 行头 | 上午（8:00-12:00）/ 下午（12:00-18:00）/ 晚上（18:00-21:00） |
| 空闲格 | #E8F5E9 浅绿底 + ✓ 图标 |
| 不可授课格 | #F5F5F5 浅灰底 + — 横线 |
| 编辑态 | 点击格切换状态，支持一键全选/清除 |
| 只读态 | 家长查看时仅展示，不可点击 |
| 宽度 | 占满卡片宽度，7列等分 |
| 格高 | 80rpx |

### 筛选条件统一规范

| 筛选项 | 交互方式 | 选项内容 |
|--------|----------|----------|
| 学科 | 下拉多选标签 | 语文/数学/英语/物理/化学/生物/政治/历史/地理/其他 |
| 年级 | 下拉单选 | 小学一年级~六年级 / 初一~初三 / 高一~高三 |
| 距离 | 下拉单选 | 1km内 / 3km内 / 5km内 / 10km内 / 不限 |
| 单价区间 | 下拉单选 | ¥0-50/时 / ¥50-80/时 / ¥80-120/时 / ¥120+/时 / 不限 |
| 院校 | 下拉单选 | 985 / 211 / 普通本科 / 不限 |

### 异常状态全局规范

| 状态 | 样式 |
|------|------|
| 无数据 | 居中插画（空盒子）+「暂无内容」文案 + 引导操作按钮 |
| 加载中 | 页面顶部细线进度条（#4A9FF5）+ 骨架屏占位 |
| 加载失败 | 居中插画（断网）+「加载失败，点击重试」+ 重新加载按钮 |
| 网络异常 | Toast提示「网络不给力，请稍后重试」 |

### ① 顶部搜索栏

| 属性 | 定义 |
|------|------|
| 高度 | 88rpx |
| 背景 | #4A9FF5 主色 |
| 组件 | 圆角搜索输入框（#FFFFFF白底，圆角32rpx），左侧🔍图标，占位文案「搜学科、年级、学校名」 |
| 右侧 | 消息铃铛图标，未读红点角标 |

**点击交互：**
- 点击搜索框 → 跳转搜索页（`/pages/search/index`）
- 点击铃铛图标 → 跳转消息中心（`/pages/messages/index`）
- 搜索框不可直接输入，仅作跳转入口

### ② 筛选条件栏

| 属性 | 定义 |
|------|------|
| 高度 | 80rpx |
| 背景 | #FFFFFF |
| 布局 | 横向5等分Tab，每Tab：图标+文字+下拉箭头 |
| 底部 | 1px分割线 #EEEEEE |

**5个筛选项布局：**

```
| 学科 ▼ | 年级 ▼ | 距离 ▼ | 单价 ▼ | 院校 ▼ |
```

**点击交互：**
- 点击任一Tab → 向下弹出半屏选择面板（高度60%屏幕）
- 面板内展示对应选项列表，多选/单选按规范
- 选中后Tab文字变色为#4A9FF5，显示已选标签
- 点击「确定」→ 关闭面板，卡片列表按条件刷新
- 点击「重置」→ 清除该筛选项
- 多个筛选条件组合生效，Tab栏展示已选数量角标

**弹窗逻辑：**
- 半屏面板从底部滑入，背景遮罩 rgba(0,0,0,0.5)
- 点击遮罩关闭面板，不改变筛选条件
- 学科支持多选，其余单选

### ③ 平台公告横幅

| 属性 | 定义 |

**点击交互：**
- 点击公告横幅 → 展开公告详情弹窗
- 点击「更多」→ 跳转公告列表页


**卡片字段明细：**

| 区块 | 字段 | 样式 |
|------|------|------|
| 左上 | 头像 | 80rpx圆形，白底边框 |
| 中上 | 院校+专业年级 | 30rpx #333333 中粗体 |

- 点击整张卡片 → 跳转老师详情页（`/pages/teacher-detail/index?id=xxx`）
- 右滑手势 → 快捷操作：收藏/私信（仅作快捷入口，不影响列表）

**列表交互：**
- 下拉刷新 → 重新加载首页数据
- 上拉加载更多 → 无限滚动，每页20条
- 滚动时筛选栏吸顶固定

| 按钮文字 | 「提交审核」（草稿态）/「重新提交审核」（驳回态） |
| 禁用条件 | 必填项未完成 → 置灰#CCCCCC |
| 激活条件 | 学科+定价+区域+日历至少1时段 → #FF8C2E |

**点击交互：**
1. 点击提交 → 弹出确认弹窗「提交后档案将进入平台审核，预计1-3个工作日」
2. 确认 → 提交请求 → Loading → 成功后跳转审核中提示页
3. 失败 → Toast「提交失败，请重试」

### 异常状态

| 场景 | 样式 |
|------|------|
| 未实名 | 顶部红色提示「请先完成实名认证」+「去认证」按钮 → 表单不可编辑 |
| 审核中 | 顶部蓝色提示 → 整个表单只读，底部按钮隐藏 |
| 已上架 | 顶部绿色提示 → 表单只读，底部显示「下架档案」灰色按钮 |
| 日历未选择任何时段 | 提交时校验 → 日历区域标红 + 提示「请至少选择1个空闲时段」 |
