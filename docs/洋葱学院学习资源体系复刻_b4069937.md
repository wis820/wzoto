# 洋葱学院小学生学习资源体系完整复刻

## 现状分析

**已有基础（可复用）**：
- 15张SQL表（user, child, membership, ai_report, learning_resource, learning_plan_config, learning_task, wrong_question_bank, feature_order 等）
- DDD四层后端架构（15个Controller、14个DomainService、14个ApplicationService）
- 11个家长端Vue页面（/learning/*）
- AI系统框架（AiGenerator接口 + MockAiGenerator + OpenAiHttpGenerator）
- 会员付费体系（MemberType枚举已含LEARNING_MONTH/LEARNING_YEAR）
- 枚举值对象（GradeType 1-6年级、TextbookVersion 7种教材版本）

**核心缺口**：
- 缺少独立的基础资源表（年级、学科、知识点、习题库、试卷库、音频素材）
- AI功能仅学情分析+教员优化，缺启发式答疑/错题分析/口语评测/作文批改/OCR
- 无学生端学习页面（当前全部是家长端视角）
- 无在线做题引擎、视频播放器组件
- 学习资源表无种子数据

## 阶段一：数据库扩展 + 基础实体（预计 15 个文件）

### 1.1 新建SQL表（8张基础资源表 + 4张AI业务表）

**基础资源表**：
- `t_subject` - 学科表（MATH/CHINESE/ENGLISH，含图标、排序）
- `t_knowledge_point` - 知识点表（按年级+学科+教材版本树形结构，parent_id自关联）
- `t_micro_course` - 微课视频表（标题、视频URL、封面、时长、分辨率、年级、学科、知识点关联、VIP标记）
- `t_exercise_bank` - 习题库表（题目内容JSON、选项JSON、正确答案、解析、难度、知识点关联、来源类型）
- `t_test_paper` - 试卷表（标题、年级、学科、试卷类型-单元/期中/期末、题目集合JSON、总分）
- `t_audio_material` - 音频素材表（标题、音频URL、类型-跟读/听力/朗读、年级、学科、文本内容）
- `t_study_material` - 学习资料表（生字卡片/思维导图/PDF、标题、类型、内容URL、年级、学科）
- `t_resource_chapter` - 教材章节表（按年级+学科+教材版本组织章节单元结构）

**AI业务表**：
- `t_ai_qa_record` - AI提问记录表（child_id、subject、question_text、question_image_url、ai_response_json-含分步解析、knowledge_tags、follow_up_question、conversation_id会话ID）
- `t_ai_grading_record` - AI批改记录表（child_id、type-COMPOSITION/PRONUNCIATION、content_text/content_audio_url、ai_result_json-含分数/建议/纠错、score）
- `t_ai_learning_plan` - AI学习规划记录表（child_id、plan_date、plan_content_json-含每日任务列表、generated_at、applied-是否已应用）
- `t_ai_exercise_generated` - AI生成练习题表（child_id、source-WRONG_QUESTION/LEARNING_PLAN、question_content_json、ai_explanation、knowledge_point）

### 1.2 领域实体 + 枚举

为每张新表创建对应的Domain Entity（@Data @Builder）、PO（@TableName）、Mapper（BaseMapper）、Repository接口+实现。

**新增枚举**：
- `SubjectType` - MATH("数学"), CHINESE("语文"), ENGLISH("英语")
- `ExerciseDifficulty` - EASY("基础"), MEDIUM("提高"), HARD("挑战")
- `TestPaperType` - UNIT("单元测试"), MID_TERM("期中"), FINAL("期末"), MOCK("模拟")
- `AiQaType` - PHOTO("拍照搜题"), TEXT("文字提问")
- `AiGradingType` - COMPOSITION("作文批改"), PRONUNCIATION("口语评测")

### 1.3 扩展AiGenerator接口

在现有AiGenerator中新增方法：
```java
// 启发式答疑 - 分步引导解题
String generateStepByStepAnswer(String subject, String questionText, String grade);

// 错题分析 - 定位薄弱知识点
String analyzeWrongQuestions(String childName, String wrongQuestionsJson);

// 学习规划 - 生成每日学习计划
String generateDailyPlan(String childName, String grade, String weakPoints, String studyTime);

// 作文批改
String gradeComposition(String grade, String title, String content);

// 口语评测（接收文本，返回评测结果JSON）
String evaluatePronunciation(String word, String audioTranscript);
```

## 阶段二：AI全链路后端实现（预计 20 个文件）

### 2.1 AI工具类封装

- `AiServiceHelper` - 统一AI请求工具类（限流、重试、超时、结构化解析）
- `OcrService` - OCR图片识别接口（预留百度OCR/腾讯OCR端口，开发阶段Mock提取文字）
- `SpeechService` - 语音评测接口（预留讯飞/百度语音端口，开发阶段Mock打分）

### 2.2 领域服务（6个新增）

- `AiQaDomainService` - AI答疑领域服务（创建提问记录、分步对话管理、会话续问、调用次数限制）
- `AiGradingDomainService` - AI批改领域服务（作文批改、口语评测、评分记录、改进建议）
- `AiLearningPlanDomainService` - AI学习规划领域服务（根据学情生成每日计划、自动关联任务）
- `ExerciseBankDomainService` - 习题库领域服务（按知识点/难度查询题目、组卷、自动批改）
- `MicroCourseDomainService` - 微课领域服务（视频播放权限、进度追踪、推荐算法）
- `KnowledgePointDomainService` - 知识点领域服务（知识点树查询、掌握度统计、图谱构建）

### 2.3 应用服务（6个新增）

- `AiQaApplicationService` - 编排AI答疑用例（权限校验→OCR→AI调用→记录→返回结构化结果）
- `AiGradingApplicationService` - 编排AI批改用例
- `AiLearningPlanApplicationService` - 编排AI学习规划用例
- `ExerciseBankApplicationService` - 编排做题用例（获取题目→提交答案→批改→错题入库→更新掌握度）
- `MicroCourseApplicationService` - 编排微课播放用例
- `KnowledgePointApplicationService` - 编排知识点查询和掌握度统计

### 2.4 Controller（6个新增，30+ API端点）

**AiQaController** `/api/ai/qa/*`：
- POST `/ask` - 提问（支持文字+图片）
- POST `/follow-up` - 追问（同一会话内续问）
- GET `/history/{childId}` - 查询提问历史
- GET `/session/{conversationId}` - 查询会话详情

**AiGradingController** `/api/ai/grading/*`：
- POST `/composition` - 作文批改
- POST `/pronunciation` - 口语评测（上传音频）
- GET `/history/{childId}` - 批改历史

**AiLearningPlanController** `/api/ai/plan/*`：
- POST `/generate/{childId}` - 生成AI学习计划
- GET `/today/{childId}` - 获取今日AI计划
- PUT `/apply/{planId}` - 应用计划到学习任务

**ExerciseController** `/api/exercise/*`：
- GET `/list` - 按条件查询习题（分页、年级、学科、知识点、难度）
- GET `/paper/{id}` - 获取试卷详情
- POST `/submit` - 提交做题结果（自动批改）
- GET `/paper/list` - 试卷列表

**MicroCourseController** `/api/course/*`：
- GET `/list` - 微课列表（分页、筛选）
- GET `/{id}` - 微课详情
- POST `/progress` - 上报观看进度
- GET `/recommend/{childId}` - 推荐微课

**KnowledgePointController** `/api/knowledge/*`：
- GET `/tree` - 知识点树（按年级+学科+教材版本）
- GET `/mastery/{childId}` - 知识点掌握度图谱

## 阶段三：学生端前端页面（7个新页面 + 组件）

### 3.1 路由配置

新增 `/student/*` 路由组，全部标记 `studentOnly: true`（学生身份）或改为双端可访问：
- 由于当前系统的identityType只有PARENT和STUDENT（大学生），需要将"小学生学习者"定位为家长端下的子用户（通过child_id切换视角），而非独立的学生身份登录
- **推荐方案**：学生端页面挂在 `/student/*` 路由下，家长可通过"切换到孩子学习模式"进入，实际使用child_id作为上下文

### 3.2 学生端页面

1. **StudentHomePage** `/student/home` - 学生学习首页
   - 今日AI学习计划卡片、推荐微课、薄弱知识点提示、每日任务进度环、快捷入口（做题/AI答疑/口语/作文）

2. **StudentCoursePage** `/student/courses` - 课程专区
   - 全科微课列表、年级+学科筛选、视频播放器（HTML5 video + 进度记录）、VIP锁定 + 会员弹窗

3. **StudentExercisePage** `/student/exercise` - 专项练习
   - 在线做题界面（选择题/填空题/判断题）、自动批改结果展示、错题一键加入错题本、难度分层

4. **StudentAiQaPage** `/student/ai-qa` - AI答疑中心
   - 拍照上传（input[type=file] + 预览）、文字输入提问、AI分步对话式回答（聊天气泡UI）、追问续问、知识点标签

5. **StudentWrongBookPage** `/student/wrong-book` - 错题本（学生版）
   - 错题列表、AI分析薄弱点、一键推送复习微课、重新做题

6. **StudentOralPage** `/student/oral` - AI口语跟读
   - 单词/课文列表、录音按钮（MediaRecorder API）、AI评分展示、发音纠正建议

7. **StudentCompositionPage** `/student/composition` - AI作文批改
   - 作文输入（标题+正文textarea）、AI批改结果（分数+错别字+病句+优化建议）、历史批改记录

### 3.3 共享组件

- `VideoPlayer.vue` - 视频播放器组件（播放/暂停/进度条/倍速/全屏、定时上报进度）
- `ExerciseCard.vue` - 做题卡片组件（选择题/填空题/判断题渲染、选项交互、提交答案）
- `AiChatBubble.vue` - AI对话气泡组件（Markdown渲染、分步展示、知识点标签）
- `KnowledgeRadar.vue` - 知识点雷达图（ECharts雷达图、掌握度可视化）

## 阶段五：学习资源种子数据 + 权限控制

### 5.1 种子数据SQL

为1-6年级 × 3学科 × 人教版生成示例数据：
- 每年级每学科 5-10 条微课视频记录（使用示例视频URL）
- 每年级每学科 20-30 道习题（JSON格式题目内容）
- 每年级 2-3 套试卷（单元测试+期中+期末）
- 基础知识点树数据（按教材章节目录组织）
- 音频素材（英语单词跟读、语文课文朗读）

### 5.2 会员权限控制完善

- 学习资源VIP标记：免费用户仅访问非VIP资源（约20%），VIP资源需学习会员
- AI功能配额：免费用户每日3次AI答疑，会员不限次数
- 新增 `FeatureType`：AI_QA_DAILY（AI答疑）、COMPOSITION_GRADE（作文批改）、ORAL_EVAL（口语评测）
