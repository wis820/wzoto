# 学霸到家 · 微信小程序产品架构设计文档

> 版本：v1.0  
> 定位：纯撮合平台 — 在校大学生 ↔ 本地家长，线下1对1家教对接  
> 核心原则：全平台实名认证 · 仅线下上门 · 双向免费发布 · 零抽成零中介费

---

## 三、各页面核心字段与交互逻辑

---

### P01 启动页/引导页

**核心字段：**
- 品牌Logo
- Slogan「学霸到家 · 真实大学生上门家教」

**交互逻辑：**
1. 自动检测登录态（token），已登录→根据身份跳转首页，未登录→跳转登录页
2. 首次使用展示3页引导轮播

---

### P02 微信授权登录页

**核心字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 微信头像 | 头像组件 | 是 | 授权获取 |
| 昵称 | 文本 | 是 | 授权获取 |
| 手机号 | 手机号组件 | 是 | 微信手机号快捷验证 |

**交互逻辑：**
1. 点击「微信一键登录」→拉起微信授权弹窗
2. 授权头像昵称后，点击「绑定手机号」→微信手机号快捷验证
3. 手机号验证成功→跳转身份选择页
4. 若已有账号→自动登录→跳转对应首页

---

### P03 身份选择页

**核心字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 身份角色 | 单选 | 是 | 家长 / 在校大学生 |

**交互逻辑：**
1. 选择身份后弹出二次确认弹窗：「身份一经选择不可随意切换，确认选择XX身份？」
2. 确认后→跳转对应实名认证页
3. 后续登录自动按已选身份进入对应首页

---

### P04 家长实名认证页

**核心字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 真实姓名 | 文本输入 | 是 | 身份证姓名 |
| 身份证号 | 文本输入 | 是 | 18位校验 |
| 身份证正面照 | 图片上传 | 是 | OCR识别辅助 |
| 身份证反面照 | 图片上传 | 是 | |
| 常住地址-省市区 | 级联选择 | 是 | 用于就近匹配家教 |
| 详细地址 | 文本输入 | 是 | 门牌号 |
| 所在小区 | 文本输入 | 否 | 同小区匹配依据 |

**交互逻辑：**
1. 填写完成后点击「提交认证」
2. 身份证OCR自动填入姓名+证号，用户可修改
3. 提交后系统自动实名校验（对接公安实名接口）
4. 校验通过→认证成功→进入家长首页
5. 校验失败→提示原因，允许重新提交

---

### P05 大学生实名认证页

**核心字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 真实姓名 | 文本输入 | 是 | |
| 身份证号 | 文本输入 | 是 | 18位校验 |
| 身份证正面照 | 图片上传 | 是 | |
| 身份证反面照 | 图片上传 | 是 | |
| 学生证正面照 | 图片上传 | 是 | 带照片页+注册页 |
| 学生证反面照 | 图片上传 | 是 | 有效期页 |
| 所在院校 | 文本输入+选择 | 是 | 全国高校列表 |
| 学历层次 | 单选 | 是 | 本科/硕士/博士 |
| 专业 | 文本输入 | 是 | |
| 年级 | 单选 | 是 | 大一~大六 |

**交互逻辑：**
1. 填写完成后点击「提交审核」
2. 身份证OCR自动填入+校验
3. 提交后进入「审核中」状态→跳转P06审核中页
4. 管理员后台人工审核（1~3个工作日）
5. 审核通过→推送模板消息→可进入大学生首页并编辑档案
6. 审核驳回→推送驳回原因→允许修改重新提交

---

### P06 认证审核中页

**核心字段：**
- 审核状态指示（审核中/已通过/已驳回）
- 驳回原因（若驳回）

**交互逻辑：**
1. 审核中：展示等待动画+预计时间提示
2. 已通过：显示「进入首页」按钮
3. 已驳回：显示驳回原因+「重新提交」按钮→跳转P05

---

### P07 家长端首页

**核心字段：**

| 区域 | 内容 |
|------|------|
| 顶部搜索框 | 搜学科/年级/学校名称，点击跳转P26搜索页 |
| 筛选栏 | 科目/年级/授课区域/价格区间/性别/名校标签，下拉选择 |
| 家教卡片流 | 院校Logo+院校名+专业+可教科目标签+课时单价+空闲时段标签+距离+评分 |
| 快捷按钮 | 「发布家教招聘」悬浮按钮，点击→P12 |
| 公告区 | 平台公告横幅轮播 |

**家教卡片字段：**

| 字段 | 说明 |
|------|------|
| 院校名称 | 如「浙江大学」 |
| 专业年级 | 如「数学系大三」 |
| 可教科目标签 | 如「小学数学」「初中物理」 |
| 课时单价 | 如「¥80/时」 |
| 空闲时段标签 | 如「周六上午」「周日下午」 |
| 距离 | 如「1.2km」 |
| 评分 | 如「4.9分」 |
| 名校标签 | 如「985」「211」 |

**交互逻辑：**
1. 下拉刷新卡片列表
2. 筛选栏支持多条件组合筛选，筛选结果实时刷新
3. 点击卡片→跳转P09老师详情页
4. 点击搜索框→跳转P26搜索页
5. 点击「发布家教招聘」→跳转P12

---

### P08 老师列表页

**核心字段：**
- 与P07卡片字段一致，增加排序切换栏
- 排序选项：距离优先 / 评分优先 / 价格最低

**交互逻辑：**
1. 顶部筛选条件栏（科目/年级/区域/价格/性别/名校）
2. 排序切换Tab，切换后列表重新排序
3. 列表无限滚动加载
4. 每张卡片右上角「收藏」心形图标，点击收藏/取消收藏
5. 点击卡片→P09老师详情页

---

### P09 老师详情页

**核心字段：**

| 区域 | 字段 | 说明 |
|------|------|------|
| 基本信息卡 | 头像、姓名、院校、专业、年级、名校标签 | |
| 擅长学科 | 科目标签组 | 如「小学数学」「初中数学」「高中物理」 |
| 定价明细 | 分段定价表 | 小学¥XX/时、初中¥XX/时、高中¥XX/时 |
| 可授课范围 | 区域文本 | 如「西湖区+拱墅区」 |

| 获奖经历 | 时间+奖项列表 | |
| 个人简介 | 富文本 | 自我介绍 |
| 过往评价 | 评价卡片列表 | 家长昵称+评分+内容+日期 |
| 底部操作栏 | 私信沟通/预约试课/收藏/下单正式家教 | |

**交互逻辑：**
1. 页面滚动查看各模块
2. 点击每周空闲日历→可查看具体时段
3. 点击「私信沟通」→跳转P22对话页
4. 点击「预约试课」→跳转P10
5. 点击「下单正式家教」→跳转P11
6. 点击「收藏」→收藏/取消收藏，toast提示
7. 评价区域展示最近评价，点击「查看全部」展开

### P10 预约试课页

**核心字段：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 选择子女 | 下拉选择 | 是 | 从子女档案选择 |
| 辅导科目 | 单选 | 是 | 取该老师可教科目 |
| 试课日期 | 日期选择 | 是 | 在老师空闲日历范围内 |
| 试课时段 | 时段选择 | 是 | 早/中/晚 |
| 上课地址 | 地址填充 | 是 | 默认取家长常住地址，可修改 |
| 联系电话 | 手机号 | 是 | 默认取绑定手机号 |
| 备注 | 文本域 | 否 | 特殊需求说明 |

**交互逻辑：**
1. 选择子女后自动填入年级+薄弱学科
2. 日期选择器仅展示该老师空闲日期（灰色不可选=不空闲）
3. 提交后生成「试课预约单」，等待大学生确认
4. 大学生确认后→双方收到模板消息提醒

## 五、竞品对标&功能取舍

### 借鉴优点
1. 多维度筛选标签
2. 老师空闲日历展示
3. 课后评价体系
4. 平台担保课时

### 摒弃痛点
1. 取消机构入驻
2. 取消高昂服务费
3. 杜绝非在校生冒充老师
4. 隐藏虚假授课时段

### 自研差异化功能
1. 大学生自定义每周可授课时间表（日历可视化）
2. 家长一键发布招聘单
3. 同小区就近匹配
4. 试课预约功能
