# 学霸到家 · 商业化产品架构文档（含盈利模型&免费/付费权限拆分）

> 版本：v2.0  
> 资金铁则：**无平台收款、无预付托管、无课时佣金抽成，彻底不做支付闭环**

```
┌─────────────────────────────┐
│ ① 顶部搜索栏 + 会员入口        │

```

#### ① 顶部搜索栏 + 会员入口

| 组件 | 说明 |
|------|------|
| 搜索框 | 圆角白底，占位「搜学科、年级、学校名」 |
| 铃铛图标 | 未读消息角标 |
| 💎会员图标 | 非会员：金色钻石图标+「开通」；会员：「已开通」灰色 |

**点击交互：**
- 点击💎 → 非会员跳转P17会员开通页；会员展示会员信息弹窗
- 免费用户：查看次数耗尽时，搜索结果页顶部提示「今日查看次数已用完，开通会员不限次数」

#### ② 筛选条件栏

5项固定筛选：学科 / 年级 / 距离 / 单价区间 / 院校

**免费/付费区分：** 基础筛选对免费用户开放【P0】，高级筛选（如按评分过滤、按空闲时段过滤）需会员【P1】。

#### ③ 平台公告

跑马灯滚动，同前版规范。

#### ④ 💎 会员权益横幅（非会员展示）

```
┌──────────────────────────────────────────┐
│ 💎 开通会员  不限查看·免费试课·AI学情诊断    │
│                           月卡¥39 年卡¥299 │
│                              立即开通 >    │
└──────────────────────────────────────────┘
```

| 属性 | 定义 |
|------|------|
| 背景 | #FFF7E6 浅金渐变 |
| 展示条件 | 仅非会员展示，会员不显示此横幅 |
| 可关闭 | 右上角✕关闭，当日不再弹出 |

**点击交互：** 点击「立即开通 >」→ 跳转P17会员开通页
