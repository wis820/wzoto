# 学霸到家 · 小学生全科学习功能说明文档

> 版本：v1.0
> 模块：家长端 P3 小学生全科学习
> 定位：对标洋葱学院，为家长端新增小学生全科学习闭环

---

## 一、功能概述

在现有家教撮合平台基础上，为家长端新增小学生全科学习模块，涵盖子女管理、学习计划、学情报告、时长管控、学习资源、错题管理、AI答疑、成长激励等功能，不改动现有家教业务流程。

## 二、复用能力清单

| 复用能力 | 来源模块 | 学习模块使用方式 |
|----------|----------|------------------|
| UserContext | 通用模块 | 获取当前登录家长userId，校验操作权限 |
| R<T> 统一响应 | Interfaces层 | 所有学习API统一返回R<T> |
| FeatureOrder 付费体系 | P1单次付费 | 学习资源解锁创建FeatureOrder |
| Membership 会员体系 | 会员模块 | 学习会员月卡/年卡权益校验 |
| MetaObjectHandler | Infrastructure层 | 自动填充createdAt/updatedAt |
| MyBatis-Plus LambdaQueryWrapper | Infrastructure层 | 所有仓储查询复用 |
| request.js Axios封装 | 前端通用 | 学习API请求复用统一拦截器 |
| showToast | 前端通用 | 学习页面消息提示 |
| global.scss | 前端通用 | .card等通用样式复用 |
| Element Plus | 前端通用 | 表单/表格/对话框等组件 |

## 三、技术架构

### 3.1 后端 DDD 四层

| 层 | 新增文件数 | 说明 |
|----|-----------|------|
| Domain | 9实体 + 9仓储接口 + 7领域服务 + 7枚举 | 核心业务逻辑 |
| Infrastructure | 9PO + 9Mapper + 9仓储实现 | 持久化与Entity↔PO转换 |
| Application | 7应用服务 | 事务编排与权限校验 |
| Interfaces | 5DTO + 9VO + 8Controller | REST API |

### 3.2 前端

| 类型 | 文件数 | 说明 |
|------|--------|------|
| API | 2 | child.js + learning.js |
| Vue页面 | 11 | 学习首页/子女/计划/任务/报告/资源/管控/错题/AI答疑/成就/会员弹窗 |
| 工具 | 1 | track.js 埋点 |
| 路由 | 11条 | /learning/* 全部标记 parentOnly |

### 3.3 数据库

9张表，MySQL 5.5兼容，不使用 `DATETIME DEFAULT CURRENT_TIMESTAMP`，使用 `DEFAULT NULL` + MetaObjectHandler填充。
