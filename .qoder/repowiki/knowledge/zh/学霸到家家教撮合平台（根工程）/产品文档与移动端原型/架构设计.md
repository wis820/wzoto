本模块为纯文档与静态资源目录，无代码依赖：
- docs/ 下按主题组织多份 Markdown 文档（产品架构设计、会员开通与付费弹窗规范、小学生全科学习功能说明、洋葱学院学习资源体系复刻、单页面原型说明），并附带自动化测试报告 HTML。
- docs/screenshots/ 集中存放各页面 UI 截图，命名以序号前缀区分（如 01_login_page.png、test_04_video_player.png），用于在文档中引用对应界面。
- prototype/index.html 是一个自包含的单页 HTML 原型，通过内联 CSS（CSS 变量定义主色/强调色/圆角等）与原生 JavaScript 实现身份切换、Tab 导航、卡片列表、详情页、周课表锁定等交互，作为前端开发前的视觉与交互参考。
该模块不引入任何构建工具或框架，所有文档与原型均可直接由浏览器打开查看。
