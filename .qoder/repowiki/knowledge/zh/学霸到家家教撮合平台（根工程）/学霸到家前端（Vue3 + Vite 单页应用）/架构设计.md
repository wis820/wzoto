采用典型的 Vue3 单页应用分层结构：入口 `src/main.js` 通过 `createApp` 挂载 Pinia、vue-router、Element Plus（中文 locale）并引入全局样式；`src/App.vue` 用 `el-config-provider` 包裹 `router-view` 作为根布局。路由集中在 `src/router/index.js`，使用 `createWebHistory` 配合懒加载 `import()` 注册所有页面，并通过 `beforeEach` 守卫实现无状态登录校验、身份选择跳转、家长/学生角色权限控制（`meta.noAuth / needIdentity / parentOnly / studentOnly`）。状态管理由 `src/stores/user.js` 中的 Pinia store 统一维护 token、用户信息、身份类型及认证状态，并提供 `login / chooseIdentity / bindUserPhone / fetchUserInfo / logout` 等 action。HTTP 层在 `src/utils/request.js` 封装 axios 实例，自动注入 Bearer Token、统一处理 401 跳转登录与错误提示；各业务 API（`src/api/*.js`）按模块拆分，仅暴露函数调用 request。页面按业务域划分到 `src/pages/{auth,learning,student,ai,profile,booking,feature,verify}` 目录，每个页面可内聚子组件于同级 `components/` 下。公共 UI 组件放在 `src/components/`，工具函数位于 `src/utils/`（format、toast、track），静态资源在 `src/assets/`。构建配置 `vite.config.js` 定义 `@` 别名指向 `src`，并通过 dev server 代理 `/api` 到 `http://localhost:8080`。
