- 页面路由统一在 `src/router/index.js` 中以对象数组集中声明，并通过 `component: () => import(...)` 实现按需懒加载。
- 路由元信息 `meta` 统一描述页面标题与权限标识（`noAuth / needIdentity / parentOnly / studentOnly`），由 `beforeEach` 守卫集中解析执行。
- API 调用按业务域拆分为独立文件（如 `auth.js`、`booking.js`、`ai.js`），每个文件导出若干命名函数，内部统一通过 `@/utils/request` 发起请求。
- 全局状态集中在 Pinia store（当前为 `user.js`）中，以 `ref` 定义响应式 state，以 `computed` 派生派生属性，以 async function 封装对外 action。
- HTTP 请求统一经 `@/utils/request` 封装的 axios 实例，利用拦截器自动注入 `Authorization: Bearer <token>` 并集中处理 401 未登录跳转。
- 页面级子组件优先放置在同级 `pages/<domain>/components/` 目录下，通用组件则放在 `src/components/`，避免跨层级耦合。
