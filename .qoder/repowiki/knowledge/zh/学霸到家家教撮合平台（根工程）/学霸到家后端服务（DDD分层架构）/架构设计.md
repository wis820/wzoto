采用标准DDD四层+基础设施的Maven多模块结构：
- wzoto-domain：纯领域模型，包含 entity/valobj/repository/service 四个子包，定义实体（如 User、LearningResource）、值对象（IdentityType、VerifyStatus 等枚举）、仓储接口及领域服务，不依赖任何框架。
- wzoto-infrastructure：实现 domain 层定义的 Repository 接口，通过 MyBatis-Plus Mapper + PO（POJO）完成数据库映射；同时集中存放配置类（JwtProperties、WechatProperties、WebMvcConfig）、拦截器（JwtAuthInterceptor）、工具（JwtUtil、WechatUtil）以及 AI 能力（OpenAiHttpGenerator、MockAiGenerator、OcrService、SpeechService）。
- wzoto-application：应用服务层，编排用例（如 AuthApplicationService 编排微信 code2Session → 领域登录 → JWT 生成），仅依赖 domain 与 infrastructure，使用 @Transactional 管理事务边界。
- wzoto-interfaces：表示层，Controller 暴露 REST API，统一返回 R<T>，全局异常由 GlobalExceptionHandler 处理；启动类 WzotoApplication 位于该模块并启用 @MapperScan("com.wzoto.infrastructure.mapper") 与 @EnableRetry。
依赖方向严格单向：interfaces → application → domain ← infrastructure（infrastructure 反向依赖 domain 以注入实现），domain 零外部框架依赖。SQL 脚本集中在 sql/ 目录，按表名或功能分组（init_all_learning_tables.sql、seed_data_*.sql、t_*.sql）。
